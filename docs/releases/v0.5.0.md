## ✦ MagicKey 0.5.0 · 메모킹 일정 추가 · 파일 끌어 놓기

### ✨ 새로 생긴 것
- 📅 **일정 추가** · 날짜가 든 글을 쓰면 `일정 추가 · 내일 (토) 오후 3시` 처럼 무엇이 저장될지 보여 주고, 누르면 메모킹 일정 탭의 빠른 추가와 같게 일정만 만들어요 (알림은 일정 탭에서 고른 기본값). 예전 "알림 맞춰 저장" 줄을 바꿨어요
- 📋 **메모 내용 복사** · 찾은 메모 줄에서 본문을 바로 복사해요 (잠긴 메모는 열기만)
- 🗂️ **파일 · 폴더 끌어 놓기** · 찾은 파일 · 폴더 줄을 끌어 바탕화면 · 탐색기 폴더에 놓으면 그곳에 복사돼요 (원본은 그대로). 메모킹 메모 창에 놓으면 첨부로 들어가요

> [!NOTE]
> 일정 추가는 메모킹 1.4.0 부터 일정만 만들어요. 그 전 메모킹이면 예전처럼 알림 맞춘 메모를 만들어요.

### 설치
아래 **Assets** 에서 `MagicKey_0.5.0_x64-setup.exe` 를 받아 실행하세요. 이전 버전 위에 그대로 설치돼요.
