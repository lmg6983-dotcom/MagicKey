## ✦ MagicKey 0.2.0 — 단축키를 내 마음대로

`Ctrl+Alt+Space` 를 다른 프로그램이 쓰고 있어도 이제 막히지 않아요. 원하는 키로 바꿔 쓰세요.

### ✨ 새로 생긴 것
- ⌨️ **단축키 바꾸기** — 알림 영역 ✦ 오른쪽 클릭 › 설정 › 단축키 바꾸기… → 새 조합을 누르면 끝
  - `Ctrl` · `Alt` · `Win` 중 하나와 함께 (예: `Ctrl+Shift+Space`, `Alt+Q`)
  - 다른 프로그램이 쓰는 키면 바꾸지 않고 알려 줘요. 바꾼 키는 다음에 켤 때도 그대로예요
- ⚙️ **설정 메뉴** — ✦ 오른쪽 클릭에 모았어요
  - 🧩 기능 켜고 끄기 (창 아래 캡슐과 함께 바뀌어요)
  - 🚀 Windows 시작할 때 켜기
  - 🔄 파일 목록 새로 만들기

### 💅 바뀐 것
- ✦ 앱 · 알림 영역 · 설치 파일 아이콘을 입력창의 노란 별 모양으로 통일했어요
- 🪧 단축키를 못 잡으면 뜨는 안내를 누르면 바로 다른 키로 바꿀 수 있어요

### 🤔 메모킹과 함께 쓴다면
메모킹은 창을 닫아도 알림 영역에 남아 `Ctrl+Alt+Space` 를 잡고 있어요. MagicKey 단축키를 다른 키로 바꾸면 둘 다 쓸 수 있어요.

### 설치
아래 **Assets** 에서 `MagicKey_0.2.0_x64-setup.exe` 를 받아 실행하세요. 이전 버전 위에 그대로 설치돼요.
