## ✦ MagicKey 0.4.4 — 단축키가 가로채이지 않고, 단축키 창이 새로 생겼어요

### 🐛 고친 것
- ⌨️ **다른 기능에 가로채이던 단축키** — `Ctrl+Alt+Space` 를 눌렀는데 `Ctrl+Space` 를 쓰는 다른 기능(입력기 등)이 먼저 받던 것. 이제 MagicKey 가 키보드에서 가장 먼저 받아요. 한국어 자판의 오른쪽 Alt(한/영) · 오른쪽 Ctrl(한자)로 눌러도 Alt · Ctrl 로 알아들어요
- 🔧 **단축키 바꾸기가 안 되던 것** — 다른 프로그램이 쓰는 조합이나 지금 단축키를 누르면 창이 닫히거나 아무 일이 없었어요

### ✨ 새 단축키 창
- ✦ 오른쪽 클릭 › 설정 › **단축키 바꾸기** 를 누르면 따로 창이 떠요
- 누르는 조합이 글쇠 모양으로 바로 보이고, 쓸 수 있는지 알려 줘요 (`Ctrl+C` · `Alt+Tab` 처럼 막는 키, `Ctrl+Space` 처럼 겹치는 키)
- 추천 조합 · 기본값으로 되돌리기 · Esc 취소

### 설치
아래 **Assets** 에서 `MagicKey_0.4.4_x64-setup.exe` 를 받아 실행하세요. 이전 버전 위에 그대로 설치돼요.
