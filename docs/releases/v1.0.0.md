## ✦ MagicKey 1.0.0 · 정식판

0.x 를 마치고 1.0 으로 올려요. 그동안 다듬은 찾기 · 메모 · OPMS · 계산 · 일정 기능이 모두 그대로 들어 있어요.

### 🐛 고친 것
- 🖼 **아이콘 깜빡임** · 찾기 창을 스크롤하거나 줄을 고를 때 앱 · 파일 · 폴더 아이콘이 선 그림으로 바뀌었다 돌아오며 깜빡이던 것을 고쳤어요
- ⚡ **더 부드럽게** · 화면에 남는 줄은 그대로 두고 새로 보이는 줄만 그려요. 한 번 받은 아이콘은 매직키 창에서도 바로 보여요

### 설치
아래 **Assets** 에서 `MagicKey_1.0.0_x64-setup.exe` 를 받아 실행하세요. 0.4.11 이상이면 저절로 업데이트돼요.
