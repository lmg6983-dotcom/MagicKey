## ✦ MagicKey 0.4.7: 단축키가 처음 한 번만 되던 것

### 🐛 고친 것
- ⌨️ **처음 한 번만 열리고 닫히던 단축키**: 창이 떠 있는지를 잘못 알아보던 것을 고쳤어요. 글을 치는 동안에도 MagicKey 는 창이 맨 앞에 있는지 Windows 에 직접 물어보고, 떠 있으면 닫고 숨어 있으면 열어요
- 🪟 **열어도 글이 쳐지지 않거나 바로 사라지던 창**: 다른 프로그램을 쓰다가 눌러도 창이 확실히 맨 앞으로 와서 바로 칠 수 있어요. 뜨는 도중에 잠깐 포커스가 흔들려도 창이 숨지 않아요
- 🔧 **단축키 창에서 튀어나오던 MagicKey**: 단축키 창이 앞에 있는 동안에는 지금 단축키를 눌러도 MagicKey 가 열리지 않아요 (새 키를 고른 뒤 저장하기 전에도요)

### 🛟 함께 다듬은 것
- 한 번 누른 단축키를 두 번 받아 열렸다 바로 닫히는 일을 한 곳에서 걸러요
- 단축키를 길게 눌러도 창이 다시 닫히지 않아요 (키 반복이 느리게 맞춰진 PC)
- `Ctrl + 한/영 + Space` 로 연 뒤 한/영 키를 뗄 때 입력기에 신호가 새지 않아요
- 안내를 보여 주고 잠시 뒤 닫히는 창이, 그사이 다시 연 창까지 닫지 않아요
- 알림 영역의 **열기** 와 두 번째 실행은 언제나 창을 띄워요

### 설치
아래 **Assets** 에서 `MagicKey_0.4.7_x64-setup.exe` 를 받아 실행하세요. 이전 버전 위에 그대로 설치돼요.
