## ✦ MagicKey 0.4.11 · 숨어 있는 동안 메모리를 덜 써요

### ⚡ 가벼워진 것
- 💤 **숨은 매직키 창** · 숨기면 메모리를 낮추고, 1분 넘게 숨어 있으면 화면 그리기도 멈춰요. 단축키로 다시 열면 그대로 되돌려요
- ✂️ **안 쓰는 크롬 기능 끄기** · 미리 띄워 두는 빈 화면 프로세스, 번역, 최적화 힌트, 미디어 캐스트, 백그라운드 네트워크, 구성 요소 업데이트를 껐어요. 매직키는 이 기능들을 쓰지 않아요

### 🔄 자동 업데이트
- 자동 업데이트 서명 키를 새로 바꿨어요. 이번 0.4.11 부터 자동 업데이트 파일이 함께 올라가요

> [!IMPORTANT]
> 0.4.10 이하를 쓰고 있다면 이번 한 번만 아래 설치 파일을 손으로 실행해 주세요. 그다음 버전부터는 저절로 업데이트돼요.

### 설치
아래 **Assets** 에서 `MagicKey_0.4.11_x64-setup.exe` 를 받아 실행하세요. 이전 버전 위에 그대로 설치돼요.
