## ✦ MagicKey 0.5.2 · 일정 캡슐 · 한글 입력 창 고침

### ✨ 좋아진 것
- 📅 **일정 캡슐** · "일정 추가"를 새 메모와 따로 켜고 끌 수 있어요. 켜 두면 날짜가 든 글(`내일 3시 치과`)에 `일정 추가 · 내일 (토) 오후 3시` 줄이 달력 아이콘과 함께 보여요 (알림 영역 기능 메뉴에도)

### 🛠 고친 것
- ⌨️ **한글을 칠 때 입력기 창이 화면 왼쪽 위에 뜨던 것** · 칠 때마다 결과에 맞춰 창 크기를 바꾸다 보니 한글 조합 중에 입력기가 커서 자리를 잃었어요. 이제 조합이 끝난 뒤에 크기를 맞춰요

### 설치
아래 **Assets** 에서 `MagicKey_0.5.2_x64-setup.exe` 를 받아 실행하세요. 0.4.11 이상이면 저절로 업데이트돼요.
